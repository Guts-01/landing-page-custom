# Pagina customizavel para seu produto 

Landing page estática e responsiva, feita com HTML, CSS e JavaScript. O tema usa a preferência de cores do sistema na primeira visita e salva a escolha feita no botão.

## Como abrir

Abra `index.html` no navegador. Não há instalação nem etapa de build.

## Personalização

- Conteúdo, navegação e marca: `index.html`
- Cores, layout e estilos dos temas: `src/screens/css/config.css`
- Comportamento do botão de tema e do contato: `src/screens/javascript/scripts.js`

Antes de publicar, troque `contato@exemplo.com` no atributo `data-contact-email` do formulário pelo e-mail real de contato. O botão **Preparar e-mail** abre o aplicativo de e-mail do visitante com a mensagem preenchida. O envio é concluído nesse aplicativo; o site não usa backend nem armazena mensagens.

A ilustração do produto é feita apenas com CSS. Você pode substituí-la por uma imagem real do produto quando tiver um arquivo definitivo.
